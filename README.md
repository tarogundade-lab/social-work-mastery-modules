# Social Work Mastery Modules

Interactive training modules for social workers moving into remote and virtual practice, built for the Remote Social Work Mastery program. Each module is a single HTML page that runs in the browser.

| Module | File | What it practices |
| --- | --- | --- |
| Before your first live session | `day1-readiness-checklist.html` | A readiness checklist for remote practice |
| Choosing your channel and documentation | `virtual-engagement-toolkit.html` | Picking phone, video, or text for a contact, and documenting it |
| Initial risk assessment: phone intake | `risk-assessment-module.html` | A branching case where decisions shape the assessment, with supervisor-style feedback |
| Risk-level triage | `risk-triage-tool.html` | A quick reference for sorting risk levels |
| Engaging a resistant client | `mi-roleplay-practice.html` | Motivational interviewing roleplay with an AI-simulated client |
| Where AI helps, where it doesn't | `ai-virtual-assistance.html` | Drafting a note with AI, then checking it against a quality checklist |
| Build an intake workflow | `automation-workflow-builder.html` | Designing an automated intake process |
| Competency reflection | `digital-impact-challenge-assessment.html` | A self-assessment of digital practice competencies |

## Running the modules

Open any file in a browser. The two AI modules (`mi-roleplay-practice.html` and `ai-virtual-assistance.html`) call the Claude API from the page and work only where that call is available, such as when the page is opened as a Claude artifact. The other modules work anywhere.

## About the cases

Every client, case, and scenario is fictional and was written for training. Do not enter real client information into the AI modules.
